# My agency

Open this folder in your coding agent and describe what you need.

- “What needs attention this week?”
- “Add a new client and start their website.”
- “Show me work waiting for approval.”
- “Prepare this month's client reports.”

Start with [AGENCY.md](AGENCY.md) and [CLIENTS.md](CLIENTS.md). Keep this workspace in a private repository. Each client's website lives in its own folder and repository.

The agent follows [AGENTS.md](AGENTS.md) and [the agency workflow](docs/AGENCY.md). Shared skills, guides and blank templates live here. Actual client work lives under `clients/`; website code stays in the corresponding site repository.
