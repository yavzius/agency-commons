- Enquiry storage, responsible recipient, delivery/retrieval method:
- Data retention, deletion, and backup/restore process:
- Search Console owner and property:
- Analytics provider, property owner, and event definitions:
- Advertising assets, consent setup, and campaign budget owner, if applicable:
- Last deployed version and recovery instructions:
- How to request and approve content changes:
- Update/monitoring responsibilities and frequency:
- What is included in maintenance and what requires a new scope:
- Export/transfer procedure if the client changes providers:
- Known limitations or unfinished work:

Demonstrate one change, one enquiry check if applicable, and one recovery scenario. Ask the client to locate the live site and identify who owns each important account. Invite appropriate roles instead of sharing a personal password. Remove temporary access when the agreed work is complete.

For multiple clients, keep separate repositories and hosting resources with clear ownership. Start with a private table of client, URL, owner, next action, renewal, and last form check. Build a shared management application only when the table stops solving the problem.
